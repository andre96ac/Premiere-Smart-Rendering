### Step di configurazione progetto:

1. Inserire l'eseguibile ffmpeg.exe in ```resources/ffmpeg```
2. ``` npm install```

<br>

### Avvio da CLI:
```
npm run build
npm run start
```
<br> 

### Avvio da GUI
```
npm run start:app
```
<br>

### Compilazione Windows Eseguibile

```
npm run dist:win
```

<br>
